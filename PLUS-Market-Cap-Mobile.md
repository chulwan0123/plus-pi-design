# PLUS Market Cap Mobile Page

## Purpose

`dist/PLUS-Market-Cap-Mobile.html` is an independent 375px mobile page for PLUS Pi ETF education visuals.

It is separate from the main PLUS design system documentation:

- Main design system document: `dist/PLUS-Design-System.html`
- Independent mobile page: `dist/PLUS-Market-Cap-Mobile.html`

Do not merge this page into the design system document unless the user explicitly asks for that.

## Separation Rules

- The page must remain standalone and directly openable as a local HTML file.
- It is not generated by `scripts/rebuild_plus_design_system_line_style.js`.
- `npm run validate` may rebuild `dist/PLUS-Design-System.html`, but it must not be treated as the source for this mobile page.
- The mobile page can reuse PLUS typography and color tokens, but its HTML/CSS should remain self-contained.
- Do not add visible labels such as "Standalone Mobile" or "Design System separated" inside the rendered page.

## Design Rules Used In This Page

- Viewport target: 375px.
- Horizontal page padding: 20px for most content sections.
- Main content width: 335px.
- Keep this page independent from `PLUS-Design-System.html`.
- Do not show internal labels such as `Standalone Mobile` in the rendered page.
- Prefer flat document sections over nested cards.
- Tables use thin lines, no heavy outer card chrome.
- Repeated table header fill: `#F7F8FA`.
- Primary accent: `Orange/60` (`#F37521`).
- Soft accent fills:
  - Orange soft: `#FFF2E5`
  - Orange stronger soft: `#FFE4CC`
  - Blue soft: `#E9F3FD`
  - Blue stronger soft: `#DEEDFC`
- Type follows the inline PLUS token layer in the HTML:
  - `type-title-1`: 24/32 bold
  - `type-body-3-bold`: 16/24 bold
  - `type-body-4-bold`: 15/22 bold
  - `type-label-1-regular`: 14/20 regular
  - `type-label-2-regular`: 13/18 regular
  - `type-label-2-bold`: 13/18 bold

## Important Implementation Details

### Market Cap Table

- Uses horizontal scrolling because visible columns exceed 375px.
- The first visible columns are rank, company name, and ticker.
- Company names are bold.
- Company logos use Google favicon URLs:

```html
https://www.google.com/s2/favicons?domain=apple.com&sz=64
```

- Berkshire Hathaway does not use an external logo. It uses the `BH` fallback.

### Long-Term Growth Visual

- Implemented as inline SVG.
- The top external title was removed.
- Visible labels inside the graph:
  - `수익 α`
  - `장기 투자로 자산 가치가 증가한 경우`
  - `총 2억 4천만 (증여 원금)`
  - `0세`, `10세`, `20세`, `30세`
- The graph plot intentionally uses the full SVG width (`0` to `335`) so it aligns with other 335px sections.
- The `수익 α` and principal labels use horizontal dashed guide lines.

### Gift Deduction Limit Visual

- Uses filled range blocks, not dot timeline or bar chart.
- Minor child:
  - left block: soft orange
  - right block: stronger soft orange
  - labels: `0세`, `10세`, `20세`
- Adult child:
  - left block: soft blue
  - right block: stronger soft blue
  - labels: `20세`, `30세~`
- Filled blocks have only top outside radius:
  - left block: top-left 12px
  - right block: top-right 12px
  - bottom radius: 0
- Vertical guide lines are `Gray/40`.
- Age labels are `Gray/60`.

### ETF Category List

- Rebuilt from Figma node `34806:29942`.
- Uses flat line-separated groups instead of cards.
- Ticker badges use `Orange/10` fill and `Orange/60` text.
- Group heading numbers were removed.
- ETF names are 15px bold.

### Logo Marquee

- Two rows.
- Each icon container is 80x80.
- Inner logo is 52x52.
- Gap is 12px.
- First row animation duration: 24s.
- Second row animation duration: 30s with `animation-delay: -10s`.
- Both rows move in the same direction but appear offset.

## Editing Guidance For Future Agents

- Edit `dist/PLUS-Market-Cap-Mobile.html` directly with scoped CSS changes.
- Keep CSS selectors specific to this file's sections.
- Do not move this content into `scripts/rebuild_plus_design_system_line_style.js` unless explicitly requested.
- Do not add visible documentation labels inside the page.
- When using Figma, inspect the exact node first, then translate into the current PLUS mobile style rather than copying the original card styling directly.
- Preserve existing Korean copy unless the user explicitly asks to change it.
- If chart/data values are challenged, verify from source before changing.
